# 智审领航 · AuditPilot — 企业级智能审计与风险核查工作台（PRD 与架构决策记录）

> **核心设计理念**：让大模型做语义理解、任务编排与归因；让确定性 SQL/Python 做算账与核对；让网关层归一化脱敏守住事务所数据保密红线；让全链路留痕与 CPA 人工复核飞轮保障审计底稿可复核。

---

## 一、 业务痛点与产品定位

- **面向场景**：会计师事务所（年报审计、IPO 审计、内控合规审查）。
- **解决 4 大核心痛点**：
  1. **算账零容错**：财务流水异常（拆分审批、重复付款、节假日/深夜大额打款）绝不能靠大模型口算，必须由确定性算子与只读 SQL 沙箱输出精确数字。
  2. **合同审查可溯源**：非标采购合同里的违约金、单方涨价、质保期缩水与数据排他条款，必须支持条款级精确页码定位与点击高亮。
  3. **账同交叉核对**：跨文件自动比对合同约定总金额/唯一指定收款账号与实际银行付款流水，消除人工核对遗漏。
  4. **数据保密与可观测**：银行账号、税号、手机号、主体名称绝不外泄给公网大模型；每次审计查询保留完整 Trace、SQL、TTFT 与降级状态。

## 二、 关键架构决策记录（Red-Teamed ADRs）

### ADR-1：脱敏下沉至 LLM 网关层 + 实体格式归一化 + 流式还原状态机
- **为什么不能在入口一刀切脱敏？** 若在入口将“华兴供应链”脱敏为 `[ENTITY_1]`，再拿占位符去查本地 SQL 或 RAG 索引，召回结果将直接归零。
- **实体归一化防误报**：合同中银行账号常带空格（`6222 0210 0112 3456 789`），流水里无空格（`6222021001123456789`）。脱敏前统一去空格/横杠归一化，确保两者映射到同一个 `[BANK_ACCT_1]`，彻底消除格式差异导致的假阳性误报。
- **SSE 流式防闪烁**：`StreamingUnmasker` 跨 chunk 缓冲 `[...]` 占位符，确保前端实时吐字时不出现残缺占位符。

### ADR-2：双层查账引擎（L1 确定性审计算子 + L2 Authorizer 只读 SQL 沙箱）
- **L1 确定性算子**：将高频审计规则（拆分规避 20 万审批阈值、3 日内重复付款、周末/法定节假日/非工作时段付款）固化为可复现的 Python/SQL 算子，零算术幻觉。
- **L2 只读沙箱**：支持即席查数，底层通过 SQLite `set_authorizer` 仅放行 `SQLITE_SELECT` / `SQLITE_READ` / `SQLITE_FUNCTION`，从引擎层拦截 `DELETE/DROP/UPDATE/PRAGMA` 注入。

### ADR-3：混合检索拆分“RRF 召回层”与“0~1 阈值精排层”，零外部 Embedding 强依赖
- **数学严谨性**：标准 RRF（$k=60$）双榜第一最高分也仅 $\approx 0.0328$，不能直接套用 0.7 阈值。本系统先用 `BM25 + 字符 n-gram TF-IDF Dense` 经 RRF 召回 Top-8，再在精排层归一化融合语义分、词频分与实体精确命中分，输出可解释的 `0~1` 相关性分数。
- **无外部 Embedding 404 风险**：不强依赖云端 `/v1/embeddings`（DeepSeek 等 Chat API 不提供该接口），内网离线环境同样开箱即用。

### ADR-4：Human-in-the-Loop 数据飞轮 + 生产级容器化交付
- **先闭环再微调**：前端每条审计结论内置 **CPA 复核按钮（✅ 确认异常 / ❌ 标记误报）**，实时写入 SQLite 并一键导出标准 **SFT / DPO JSONL** 训练语料，体现企业级 AI 演进思路（先 RAG+确定性工具跑通业务，再基于 CPA 复核飞轮微调/蒸馏垂直小模型）。
- **云原生部署**：仓库内置多阶段非 root `Dockerfile`、`docker-compose.yml` 与 `k8s/deployment.yaml`（含健康探针与 Nginx Ingress 关闭缓冲/延长 SSE 超时配置）。

## 三、 面试 3 分钟现场演示话术（容诚社招高级版）

1. **开场 30 秒（定调架构）**：展示顶部状态栏，点出“确定性算账 + 混合 RAG 溯源 + 网关归一化脱敏 + LangGraph 编排 + CPA 复核飞轮”五大闭环。
2. **核心演示 1 分钟（全量一键审计 + 原文溯源 + 脱敏透视）**：
   - 点击左侧 **「1. 全量一键综合审计」**，展示 SSE 实时流式输出与 LangGraph 节点轨迹；
   - 点击回答里的 **`[证据:DOC-...]`** 按钮，右栏自动滚动高亮合同对应条款页码；
   - 切到右栏 **「脱敏透视」**，展示外发 Prompt 零泄露校验及跨格式银行账号归一化映射。
3. **工程深度 1 分钟（高可用降级 + SQL 沙箱 + 数据飞轮 + 自动化评测）**：
   - 勾选顶部 **「主模型故障演练」** 再发一次请求，演示主模型超时自动降级至备用模型/本地兜底引擎；
   - 点击底部的 **「✅ CPA确认异常」** 与顶部 **「⬇ 导出 SFT 飞轮」**，展示审计底稿导出与训练语料沉淀；
   - 点击 **「📊 一键评测」**，现场展示 12 条黄金测试用例通过率、Hybrid vs BM25 Recall@3 对比及 TTL 缓存加速比。
4. **收尾 30 秒（对接容诚落地演进）**：打开 `k8s/deployment.yaml` 说明内网私有化部署（vLLM/SGLang + Harbor + K8s + SSE Ingress 配置）以及按项目组做多租户 RBAC 隔离的演进路径。
